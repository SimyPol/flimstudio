# FLIM Studio 0.11.3

## Log/linear intensity toggle

New **"Log-scale intensity"** checkbox in the Overview tab's SECOND MAP
toolbar (on by default, matching prior behaviour). It controls every
intensity rendering in the app together:

- The primary Intensity panel
- The second map's "Intensity" option
- The second map's "Intensity with threshold" option (the red/grey
  omitted-pixel preview)
- The raw photon-count view shown before you've run an analysis

Each subtitle now states which scale is active. Exports (PNG/NPZ dashboard
previews) are unaffected and still use log scale, since that wasn't part of
what was asked for — say the word if you'd like exports to follow the
toggle too.

## Square phasor plot

Found the actual cause of the phasor plot looking off: the G axis (range
−0.1…1.1) and S axis (range 0…1) had different pixel-per-unit scales, so
the universal semicircle was rendered slightly stretched rather than a true
semicircle, even though the app already draws it as a geometrically correct
circle segment.

- The plotting rectangle is now a true square, centred within the same
  overall image size as before (so nothing that reads `phasor_plot()`'s
  output dimensions needed to change).
- S now uses the same −0.1…1.1 range as G (matching what this project's own
  earlier documentation described as the LabVIEW-accurate range for both
  axes) instead of 0…1, so one G unit and one S unit now cover the exact
  same number of pixels.

Because the plot area is now square inside a wider canvas, there's a bit of
empty side padding around it — let me know if you'd rather I also shrink
the canvas to fit tighter.
