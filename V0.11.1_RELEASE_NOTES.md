# FLIM Studio 0.11.1

## Shared IRF/background in the Training dialog

The training dialog previously asked for a fresh IRF (and, per image,
whether to add a background) every single time you clicked **Add image…**,
even though the underlying DLL already supports one shared IRF for the
whole training stack (`irfMode 0`).

- New **Shared IRF** / **Shared background** pickers at the top of the
  Training dialog. Set either once and every image added afterwards reuses
  it automatically — no more per-image prompts.
- Leave either unset and the dialog falls back to asking per image, exactly
  as before, so mixed training sets (some images sharing an IRF, others
  with their own) still work.
- **Clear** reverts to per-image prompting for anything added from that
  point on; images already added keep whatever they were given.
- To actually train under "one shared IRF for all images," also set the
  sidebar's **IRF mode** to **Global IRF** (this only controls what the
  dialog asks for while you're building the set — the sidebar's IRF mode is
  still what tells the DLL how to treat it).
