# FLIM Studio 0.10.2

## Zoom and pan on every image/plot panel

Added generically to the shared `ImageView` widget, so it applies to
Intensity, the secondary map (Lifetime/Composite/Threshold), Decay & fit,
Phasor, Histogram, both ROI decay panels, and every Multi-exponential
τ/A component map — no per-view code needed.

- **Mouse wheel**: zoom in/out, centred on the cursor position (1.0x–16x).
- **Right-click + drag**: pan while zoomed in.
- **Plain right-click** (no drag): unchanged — still clears the current ROI,
  exactly as before zoom existed.
- **Zoom badge**: a small "NNN% · click to reset" tag appears in the
  top-right corner whenever zoomed; click it to reset to fit-to-window.
  Left-click/drag (point placement, ROI selection) is unaffected everywhere
  else on the canvas.

At the default zoom level (1.0x, "fit to window") rendering, selection, and
point-placement math is unchanged bit-for-bit from pre-zoom behaviour — zoom
only kicks in once the user actually scrolls, so existing tests that
synthesize click/drag events via `view._display_box` continue to pass
without modification.
