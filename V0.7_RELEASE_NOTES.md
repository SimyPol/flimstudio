# FLIM Studio 0.7 — acquisition parity update

This release addresses the supplied sample, background, and IRF acquisitions.

## Background correction

- A loaded acquisition background is now corrected before timing shifts,
  detector-row interpolation, smoothing, spatial binning, phasor analysis, or
  fitting.
- The exact operation is
  `clip(sample - multiplier × background - scalar_background, 0, +inf)`.
- Automatic scaling uses sample/background scan-loop counts first, acquisition
  times second, and the explicit 0.025 fallback otherwise.
- For the supplied files, both `20 / 800` loops and `5 / 200` seconds resolve to
  an applied multiplier of exactly 0.025.
- Time-bin count and width are validated before subtraction, and the applied
  factor, derivation, clipping fraction, source, and operation order are saved
  in every result JSON.

## Distinct bin controls

- 32 acquisition TCSPC bins, read from the ICS file.
- 29 native FLIMLib input bins, matching the saved Slimcurve control; `-1`
  selects all acquisition bins.
- 50 compact Overview lifetime-histogram intervals.
- 1000 detailed/export lifetime-histogram bins.

These quantities are labelled separately and exported in
`metadata.time_bin_contract`.

## Thresholds and displays

- Phasor and fit/native count gates are independently configurable; the
  supplied mono-fit configuration uses 1000 total processed counts.
- The lifetime map now uses the byte-exact 256-entry
  `Reverse Rainbow (DM).lut` from the LabVIEW workflow, with the saved
  0.5–4.5 ns range and display-only out-of-range removal.
- The composite remains a separate LabVIEW-style HSV rendering (hue 0–0.7,
  saturation 1, linearly auto-scaled intensity); the original VI did not use
  the lifetime LUT for that composite.
- Numerical lifetime values are no longer discarded merely because they fall
  outside the chosen display range.

## Supplied-file validation

The supplied 512×512×32 sample was processed with its matching 32-bin IRF and
background. The automatic correction resolved `20 / 800 = 0.025`, validated
the common 0.390625 ns bin width, and completed all exports. The validation run
produced 171,971 phasor-valid pixels, median phase lifetime 2.767 ns, and a
maximum corrected integrated intensity of 14,166.25 counts. These figures are
a software/data-flow check, not a biological interpretation or publication
standard.
