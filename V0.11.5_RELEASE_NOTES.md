# FLIM Studio 0.11.5

## Overview tab: Phasor and Histogram shown together, not toggled

My previous change (v0.11.4) merged the separate dedicated *Phasor* and
*Histogram* tabs — but that wasn't what was meant. This one fixes the
actual target: the **Overview tab**'s "Selected phasors" panel, which
previously had a **Phasor/Histogram** dropdown that swapped a single panel
between the two.

- That dropdown is gone. The panel now shows **both** at once, side by
  side, always in sync with your current ROI/point selection.
- **"Selected-point decays"** (the panel on the left) is untouched — same
  column, same width as before. Only the right-hand panel changed, from one
  swappable view into two smaller views sharing that same space.

The dedicated "Phasor & Histogram" tab from v0.11.4 is unaffected and still
there for the full-size versions of both.

## Verification

- Updated `tests/gui_smoke_v06.py` and `tests/gui_smoke_v07.py` (both
  exercised the old scope-toggle dropdown) to check the new always-both
  layout instead: both panels present with fixed titles, correct grid
  position, and the phasor panel's cached image still changes appropriately
  as points/ROI selection changes.
