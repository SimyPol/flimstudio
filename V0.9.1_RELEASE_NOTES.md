# FLIM Studio 0.9.1

- The secondary-map choices now explicitly include **Intensity** and
  **Intensity with threshold**. The threshold image redraws immediately.
- Native-fit threshold preview now uses the exact native input-count basis
  (the leading 29 TCSPC bins in the supplied preset), matching FLIMLib rather
  than displaying the full 32-bin intensity near the cutoff.
- **Use for fit** routes the preview threshold to the phasor gate for phasor
  methods, or the fit/native gate for fitted methods.
- Phasor density, axes, semicircle and selected markers now share the saved
  LabVIEW G/S display limits of -0.1 to 1.1.
- A regression test transcribes the supplied embedded MATLAB equations. The
  Python implementation matches its per-pixel IRF median subtraction, complex
  division and half-bin phase correction to floating-point precision.
