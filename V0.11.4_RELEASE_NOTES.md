# FLIM Studio 0.11.4

## Phasor and Histogram share one tab, side by side

The Phasor and Histogram tabs are now a single **"Phasor & Histogram"** tab
with the two plots side by side, instead of each getting its own
full-width tab. The square phasor plot (v0.11.3) was leaving a lot of
empty space either side of it in a full-width tab; putting it next to the
histogram uses that space instead.

Also shrank the phasor plot's own default canvas from 760×430 down to
504×460 — margins sized so the square plotting area now fills essentially
the entire canvas (previously there was also padding *inside* the phasor
image itself, on top of the tab being too wide for it). Callers that pass
an explicit size (the composited dashboard preview, the fixed-layout
export panel) are unaffected; only the default changed.
