# FLIM Studio 0.12.0

## Phasor plot rebuilt from scratch

`phasor_plot()` is a fresh implementation. Kept exactly as requested: the
violet→blue→cyan→green→yellow→red density colour ramp and the red
universal semicircle. Everything else is new:

- **Anti-aliased rendering.** The whole plot is drawn at 3x resolution and
  downsampled with LANCZOS at the end. PIL's drawing primitives have no
  built-in anti-aliasing, so at native resolution the semicircle, gridlines,
  and text all had visibly jagged edges before — now they're smooth. This
  also has a nice side effect on the density map itself: histogram bins
  are still rendered as clean blocks, but the final downsample softens
  them into a smooth gradient instead of a hard-edged blocky look, without
  touching a single colour value in the ramp.
- **Interior gridlines.** Faint lines every 0.2 G/S units, so you can read
  off an approximate coordinate without hunting at the plot edge.
- **Cleaner axis ticks.** Minor ticks every 0.1, labelled major ticks every
  0.2 (previously every tick was labelled, which was cluttered).
- **Labelled density key.** "High"/"Low" labels and a rotated "Density"
  label next to the colour bar — it was completely unlabelled before.
- **Sharper points and semicircle.** Both benefit directly from the
  supersampling; the semicircle is also drawn with smoothed line joints.

The output image dimensions are unchanged (still whatever `size` is
passed, default 504×460), so nothing that reads `phasor_plot()`'s output
size needed to change.

  render has gridlines crossing the plot area and a supersample/downsample
  step, rather than a perfectly flat black interior.

  `tests/test_v09_features.py::test_heatmap_and_threshold_preview`,
  `tests/gui_smoke_v10.py`) exercise both the heatmap and scatter code
