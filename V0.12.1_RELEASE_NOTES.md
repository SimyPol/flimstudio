# FLIM Studio 0.12.1

## Standalone executable packaging

FLIM Studio can now be packaged into a standalone `FLIM Studio.exe` that
runs on a machine with no Python installed, via
[PyInstaller](https://pyinstaller.org/). See [BUILDING.md](BUILDING.md)
for full instructions; short version:

```bash
build_exe.bat
```

or `pyinstaller --noconfirm flim_studio.spec` directly. Output lands in
`dist\FLIM Studio\` -- distribute that whole folder (zip it up), not just
the `.exe` inside it.

### Code changes required to make freezing work

Two things about this app don't survive being frozen by PyInstaller
unmodified:

1. **Native fits run in a subprocess** for crash isolation from a DLL
   access violation. From source that subprocess is
   `python native_worker.py ...`; frozen, there's no standalone
   `native_worker.py` file on disk to spawn. `run_flim_studio.py` now
   checks for a hidden `--native-worker` argv flag before importing
   anything GUI-related, and `native_backend.py`'s
   `_run_native_subprocess()` relaunches the frozen exe itself with that
   flag instead of spawning a script file when `sys.frozen` is set.
2. **Bundled data files** (the fitting DLL, the default LUT) can't be
   found via `Path(__file__).resolve().parent` once frozen, since source
   files get compiled into an archive rather than existing as loose files
   at that path. New helper [`flim_app/_paths.py`](flim_app/_paths.py)
   resolves these consistently in both source and frozen (via
   PyInstaller's `sys._MEIPASS`) modes; `lut.py` and
   `native_backend.py`'s DLL search both now use it.

### New files

- [`flim_studio.spec`](flim_studio.spec) -- PyInstaller build spec
  (onedir, bundles the native DLL and default LUT)
- [`build_exe.bat`](build_exe.bat) -- convenience build script
- [`BUILDING.md`](BUILDING.md) -- prerequisites, build steps, and
  troubleshooting (DLL-not-found, missing VC++ Redistributable,
  AV/EDR false positives, missing PyInstaller hidden imports)

### Confirmed working

Built and run end to end (2026-08-18): the exe launches, and a full
analysis run against the bundled demo data works, including native
fitting, the phasor plot, lifetime histogram, multi-exponential tab, and
metadata provenance. `build_exe.bat`'s interpreter auto-detection was
tightened afterwards to test each candidate Python for a working
PyInstaller import rather than just checking PATH, after it initially
picked the wrong one on a machine with more than one Python installed.
